# Pricing Panel

A responsive Pricing Panel built using HTML and CSS. This project showcases different pricing plans in a clean and user-friendly layout, helping users compare available plans and their features easily.

## Features

- Clean and modern user interface
- Multiple pricing plans displayed in a structured layout
- Clear pricing and feature comparisons
- Styled buttons and interactive-looking elements
- Responsive design for different screen sizes (if implemented in CSS)

## Technologies Used

- **HTML5** – Used to structure the pricing panel and its content.
- **CSS3** – Used for styling, layout, colors, spacing, and visual design.

## Project Structure

```text
Pricing-Panel/
├── index.html
├── style.css
└── README.md
```

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser, or run it using the Live Server extension.
